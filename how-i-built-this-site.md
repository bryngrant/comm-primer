# How I built this site

This site is built with Jekyll for GitHub Pages. The structure uses a shared layout, a custom royal-blue visual theme, and separate pages for each communication lens so the project can scale as content grows.

## Tool stack and layout decisions

- Jekyll powers static page generation.
- A GitHub Actions workflow builds and deploys the site when commits land on `main`.
- A reusable layout keeps navigation, accessibility landmarks, and styling consistent.
- A dedicated images folder supports visual examples and figures.

## Agent involvement

A coding agent scaffolded the Jekyll project, created the page structure and starter text, implemented accessible navigation and ARIA landmarks, added theme styling, and configured the GitHub Actions workflow.
